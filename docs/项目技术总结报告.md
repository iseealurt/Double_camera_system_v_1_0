# FPGA双目立体视觉系统 -- 项目技术总结报告

## 一、项目概述

本项目是一个完整的**基于FPGA的双目立体视觉系统（DC-CVS, Double-Camera Computer Vision System）**，在国产FPGA平台（MES50HP, Pango Design Suite工具链）上实现了从双摄像头图像采集到视差图输出的全硬件流水线。系统使用两颗OV5640摄像头同步采集640x480双目图像，通过DDR3 SDRAM帧缓存和AXI总线互联架构，在FPGA内部完成Census变换 + SGM（Semi-Global Matching，半全局匹配）立体匹配流水线，最终通过HDMI 1080P输出视差图显示。

## 二、技术架构总览

### 2.1 完整数据流

```
OV5640_1 --> DVP采集 --> VESA_AXI(写) --> DDR3 Bank0
OV5640_2 --> DVP采集 --> VESA_AXI(写) --> DDR3 Bank1
                                              |
              AXI仲裁器(4主1从) <---------------+
                                              |
    sgm_data_engine(读) <-- DDR3 <-- AXI仲裁器
              |
    rgb2gray (左/右) ×2
              |
    census_5x5 (左/右) ×2
              |
    Census FIFO (跨时钟域: pix_clk --> sgm_clk)
              |
    SGM核心算法 (sgm_clk域)
              |
    VESA_AXI(写) --> DDR3 Bank2
              |
    sgm_disp(读) --> HDMI 1080P 叠加显示
```

### 2.2 时钟域设计

| 时钟域 | 频率 | 功能 |
|--------|------|------|
| sys_clk | 50MHz | 系统主时钟、UART、初始化序列 |
| cmr_1_pclk | OV5640输出 | 摄像头1像素采集 |
| cmr_2_pclk | OV5640输出 | 摄像头2像素采集 |
| pix_clk | DDR PLL输出 | RGB转灰度、Census变换、显示时序 |
| sgm_clk | DDR PLL输出 | SGM算法核心计算 |
| axi_clk | DDR控制器 | AXI总线 / DDR3访问 |

跨时钟域策略：异步FIFO（像素数据流）+ 多级寄存器同步器（控制信号）+ 双FIFO架构（VESA_AXI）。

### 2.3 存储架构

- **DDR3 Bank0/1**: 摄像头1/2帧缓存
- **DDR3 Bank2**: SGM视差输出缓存
- **DDR3 Bank3**: 视差图显示读取缓存
- **BRAM**: 各FIFO（像素FIFO 256bit×8深、Census FIFO、地址FIFO等）
- **寄存器阵列**: Census 5×5矩阵移位寄存器、SGM XOR窗口寄存器

## 三、RTL模块清单与分析

### 3.1 系统顶层

| 模块 | 路径 | 功能 |
|------|------|------|
| OV_DDR_HDMI_v_2_0 | RTL_code/Top/ | SoC顶层，集成全部子系统 |
| SGM_TOP | RTL_code/ | SGM算法子系统封装 |
| video_init | RTL_code/Top/ | 系统初始化序列控制器（DDR→摄像头→HDMI） |

### 3.2 SGM算法核心

| 版本 | 路径 | 视差数 | 路径数 | 备注 |
|------|------|--------|--------|------|
| sgm_new_2 | RTL_code/algorithm/ | 48 | 1路(Lr0) | 系统集成版 |
| sgm_new_3 | SGM_4_PATH/RTL/ | 32 | 4路 | 完整4路聚合+比较树 |
| sgm_new_4 | SGM_4_PATH/RTL/ | 32 | 4路 | 4路代价计算+基础聚合 |

**SGM算法流水线（12级）**：
- Stage 0: Census数据读取 + XOR窗口构建
- Stage 1: Census XOR异或计算
- Stage 2: 基于LUT6的popcount第一级
- Stage 3: popcount第二级 + 左视差掩码
- Stage 4: Hamming距离输出
- Stage 5-6: R参数计算 + min4 + Lr_curr
- Stage 7-8: 两级比较树求Lr_prev_min
- Stage 9: 最小值锁存 + RAM写入

**代价聚合公式**:
```
Lr(p,d) = C(p,d) + min(Lr(p-r,d), Lr(p-r,d-1)+P1, Lr(p-r,d+1)+P1, min_k Lr(p-r,k)+P2) - min_k Lr(p-r,k)
```
参数: P1=3, P2=24, 4路径聚合方向 Lr0/Lr1/Lr2/Lr3

### 3.3 图像预处理

| 模块 | 功能 | 关键设计 |
|------|------|----------|
| rgb2gray | RGB→灰度 | 4级流水线：Gray = (R×19595+G×38470+B×7471)>>16 |
| matrix_5x5 | 5×5滑动窗口 | 4个FIFO_8w1024d级联行缓存 + 移位寄存器 |
| census_5x5 | Census特征变换 | 24bit特征（跳过中心p33），邻域>中心→1 |

### 3.4 总线与接口

| 模块 | 功能 |
|------|------|
| VESA_AXI_v_3_0 | VESA像素流→AXI4写接口，burst自动分片 |
| sgm_data_engine | AXI读请求 → VESA显示信号 + 像素输出 |
| sgm_disp | 视差图在1080P画面上叠加显示 |
| uart_rx / uart_tx | UART调试接口 115200bps |
| Disp_param.vh | 1080P VESA时序参数定义 |

### 4.2 核心验证范式

**数据采集 + MATLAB后处理**：Testbench采集FPGA流水线各阶段输出到.dat文件 → MATLAB脚本逐像素精度比对。

6路并行数据采集（tb_sgm_new）:
- Task 1/2: 左右目灰度图
- Task 3/4: 左右目Census特征
- Task 5: 最终视差图
- Task 6: Stage4汉明距离中间结果

### 4.3 MATLAB验证脚本矩阵

| 脚本 | 功能 |
|------|------|
| verify_fpga_sgm.m | FPGA vs MATLAB 多路SGM + Ground Truth对比（AvgErr / Bad1.0指标） |

### 4.4 AXI验证模型

`axi_mem_test_model.v`：可综合风格的AXI4存储器行为模型（替代DDR控制器加速仿真），支持$readmemh加载.dat图像数据、随机访问延迟模拟（3-10周期）、事务缓冲区（深度8/16）、读通道完整AXI握手。

### 4.5 仿真工具链

## 五、FPGA实现技术

### 5.1 设计技术

| 技术 | 应用 |
|------|------|
| 全流水线设计 | rgb2gray(4级) → SGM(12级)，每级1拍吞吐 |
| 脉动阵列 | 4路lr_num_cnt时分复用控制器 |
| LUT优化 | 基于case语句的6-bit popcount查表 |
| 两级比较树 | 5×6+2=32元素 → 6路并行 → 7选1最终min |
| FIFO行缓存 | 4级FIFO级联实现5行滑动窗口 |
| 移位寄存器延迟链 | 12/13级数据/控制信号延迟对齐 |

### 5.2 FPGA实现工具链

- **FPGA平台**: MES50HP（国产FPGA）
- **综合/布局布线**: Pango Design Suite 2022.2-SP6.4
- **开发流程**: 编译 → 综合 → 设备映射 → 布局布线 → 时序报告 → 功耗报告 → 生成比特流
- **约束文件**: IO引脚约束(.pcf) + 时序约束(.fdc)

### 5.3 IP核清单

| IP核 | 用途 |
|------|------|
| DDR3 SDRAM Controller | DDR3存储控制器 |
| FIFO_8w1024d ×4 | matrix_5x5行缓存 |
| fifo_256b6d / fifo_24d6d | VESA_AXI跨域FIFO |
| drm_fifo_256b_8d ×2 | SGM_TOP像素缓冲 |
| cmr_census_fifo / sgm_vsync_fifo | Census跨时钟域FIFO |
| sgm_lr0_ram / sgm_lr2_ram | SGM代价聚合路径缓存 |

## 六、MATLAB算法工程

### 6.1 算法探索路径

多版本迭代：
- `sgm_single_path.m`: 单路径L→R SGM
- `sgm_single_path_enhanced.m`: 双路径(LR+RL)增强
- `sgm_4_path.m`: 4路径 + 7×7 Census + 完整后处理 + Middlebury评估
- `new_sgm.m`: 按Verilog流水线步骤1:1复现

### 6.2 后处理算法

| 算法 | 实现位置 |
|------|----------|
| WTA（优胜者通吃） | FPGA + MATLAB |
| 唯一性约束 | MATLAB |
| 左右一致性检查（LR Check） | MATLAB（阈值=1） |
| 中值滤波（5×5） | MATLAB |
| Speckle滤波（面积<80） | MATLAB |
| 亚像素插值（三点抛物线） | MATLAB |
| DP空洞填充（4方向） | MATLAB |

### 6.3 相机标定

`stereo_calibration.m`：使用MATLAB Computer Vision Toolbox进行棋盘格检测 → 单目标定 → Bouguet立体校正 → 生成畸变+校正合并LUT。
