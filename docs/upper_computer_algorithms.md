# 上位机软件算法调研

## 概述

本项目上位机软件需要处理后续硬件传入的三种模态数据：
- **RGB 可见光图像**
- **视差图（深度图）—— 来自 FPGA SGM 立体匹配**
- **红外热成像图**

上位机软件需实现以下四大功能模块的算法集成。

---

## 一、多模态数据融合处理

### 1.1 融合策略对比

| 融合策略 | 说明 | 适用场景 |
|---------|------|---------|
| **早期融合（Early Fusion）** | 在输入层直接拼接多模态数据（如 RGB + Depth 拼接为 4 通道输入） | 简单零件尺寸检测 |
| **中期融合（Mid-Level Fusion）** | 各模态分别经 CNN/Transformer 提取特征后，在特征层进行 Cross-Attention 融合 | 工业缺陷检测主流方案 |
| **晚期融合（Late Fusion）** | 各模态独立推理后加权投票或分数融合 | 鲁棒性要求高的场景 |

### 1.2 推荐算法/框架

| 算法 | 来源 | 特点 | 性能指标 |
|------|------|------|---------|
| **G²SF** | ICCV 2025 | 几何引导分数融合，RGB-D 工业异常检测专有 | AUROC 98.2%, 45 FPS, 27.5M 参数 |
| **多模态 Transformer** | 2025 研究前沿 | 跨模态注意力机制，超越传统 CNN 15-20% | 特征层深度融合 |
| **轻量化跨模态注意力（LCA）** | Array 期刊 2025 | 共享双分支 ResNet-50，RGB 通道注意力 + Depth 空间注意力 | AUROC 98.3%, AUPRO 81.1% |

### 1.3 PC 部署建议

```
推荐技术栈：PyTorch + ONNX Runtime / OpenVINO
最低 GPU：NVIDIA GTX 1660 (6G) 或 Intel 集成显卡（OpenVINO 优化后）
```

## 二、YOLO v8 目标检测算法

### 2.1 核心特性

- **Backbone**：CSPDarknet 结构，高效多尺度特征提取
- **Neck**：FPN+PAN 增强路径聚合，提升多尺度检测能力
- **Head**：Anchor-Free 设计，简化预测头
- **支持任务**：检测（Detection）、分割（Segmentation）、分类（Classification）、姿态估计（Pose）

### 2.2 PC 部署性能

| 模型版本 | GPU (RTX 3060) | CPU (i7-12700H) | mAP@50 |
|---------|---------------|----------------|--------|
| YOLOv8n | ~120 FPS | ~30 FPS | 37.3 |
| YOLOv8s | ~100 FPS | ~20 FPS | 44.9 |
| YOLOv8m | ~60 FPS | ~10 FPS | 50.2 |
| YOLOv8l | ~40 FPS | ~5 FPS | 52.9 |

### 2.3 PC 部署方案（推荐优先级）

**方案 1：Ultralytics 原生部署**（最简单，快速验证）
```python
from ultralytics import YOLO
model = YOLO("best.pt")
results = model.predict("image.jpg")
```

**方案 2：ONNX + ONNX Runtime**（推荐生产环境）
- 速度较原生提升 20-30%
- 支持跨平台（Windows/Linux/macOS）
- 可导出 FP16 量化模型

**方案 3：OpenVINO 优化部署**（Intel CPU/GPU 最佳方案）
- FP16 量化后推理速度提升 2-3 倍
- 支持 Intel 集成显卡推理加速

## 三、缺陷检测算法

### 3.1 方案对比

| 方法 | 准确率 | FPS | 适用场景 |
|------|--------|-----|---------|
| **传统 OpenCV**（Canny + 轮廓分析） | 85-92% | 60+ | 规则纹理、高对比度缺陷 |
| **YOLOv8 检测** | 93-96% | 30-60 | 通用缺陷分类 + 定位 |
| **U-Net 分割** | 95-98% | 20-30 | 需要像素级缺陷分割 |
| **RT-DETR**（实时 Transformer） | 91.6%+ | 40+ | 小目标缺陷检测 |
| **Ultra-ViT**（视觉 Transformer） | 97.73% | 30+ | 超声/红外谱图缺陷识别 |

### 3.2 工业实战推荐方案

**方案 A：传统 + 深度学习组合（最常用）**
```
OpenCV 形态学预处理 → YOLOv8 检测 → 几何分析排除误检
```

**方案 B：端到端深度学习（按场景选择）**
- **PCB 表面缺陷** → 改进 EP-RTDETR（mAP 提升 4.6%，参数量减少 16.38M）
- **焊缝 X 光缺陷** → CADETR（基于 DETR 改进，mAP 91.6%）
- **金属表面缺陷** → Ultra-ViT（时频域 + Vision Transformer，准确率 97.73%）

## 四、工件姿态估计算法

### 4.1 问题定义

6D 姿态估计：输出物体在三维空间中的 **6 自由度位姿**（3 个平移 + 3 个旋转），即旋转矩阵 R、平移向量 t。

### 4.2 主流算法对比

| 算法 | 年份 | 输入 | 特点 | 精度（LineMOD） |
|------|------|------|------|----------------|
| **DenseFusion** | 2019 | RGB-D | 稠密像素级融合，开创性工作 | ADD(-S) 86.2% |
| **PVN3D** | 2020 | RGB-D | 关键点检测 + 3D 投票，更鲁棒 | ADD(-S) 91.8% |
| **SDFR（哈工大）** | 2025 TRO | RGB-D + SDF | 隐式神经表面优化，遮挡鲁棒 | ADD(-S) 95.6% |
| **自适应多模态融合** | 2025 | RGB-D + 法线 | 三分支自适应融合，弱纹理优化 | 显著优于基线 |

### 4.3 PC 部署建议

```
推荐框架：PyTorch3D + PointNet++
GPU 要求：NVIDIA RTX 2060 (8G) 以上
推理速度：DenseFusion ~30 FPS, PVN3D ~25 FPS
```

### 4.4 典型应用流程

1. RGB-D 图像采集（或从视差图 + 红外图生成类点云数据）
2. 2D 目标检测（YOLOv8）获取 ROI
3. 在 ROI 内进行 6D 姿态回归
4. 输出旋转矩阵 R + 平移向量 t → 机械臂抓取 / 装配引导

```

┌─────────────────────────────────────────┐
│  多模态数据采集与对齐（时间戳同步）        │

├─────────────────────────────────────────┤
│  多模态融合层（中期融合 / 跨模态注意力）    │
│  ┌──────────┬───────────┬───────────┐  │
│  │ YOLOv8   │ 缺陷检测  │ 姿态估计   │  │
│  │ 目标检测 │ (U-Net/   │ (PVN3D/   │  │
│  │          │ RT-DETR)  │ SDFR)     │  │
│  └──────────┴───────────┴───────────┘  │
├─────────────────────────────────────────┤
│  ONNX Runtime / OpenVINO 推理加速        │
├─────────────────────────────────────────┤
│  上位机界面（PyQt / C# WPF / Qt）        │
└─────────────────────────────────────────┘
```
